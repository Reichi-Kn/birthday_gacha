# Birthday Gacha

21歳の誕生日サプライズ用・スマホ向けガチャガチャWebアプリです。

## Netlifyへのデプロイ

このフォルダ（`index.html` がある階層）を、そのまま Netlify にドラッグ＆ドロップするだけで公開できます。
ビルドコマンドやフレームワークの設定は不要です。

1. https://app.netlify.com/drop を開く
2. このフォルダをまるごとドラッグ＆ドロップ
3. 発行されたURLをスマホで開けば完成

## カスタマイズ方法

### 1. プレゼントの個数（`script.js` 冒頭 `CONFIG.totalCount`）

```js
totalCount: 20,
```

20個以外にしたい場合はこの数字を変えるだけです。番号グリッドや進行状況の表示（例: `3 / 20`）にも自動的に反映されます。

### 2. カプセルの出る確率（`script.js` 冒頭 `CONFIG.rankWeights`）

```js
rankWeights: {
  green: 60,
  red: 30,
  gold: 10,
},
```

各ランクの「重み」を数字で指定します。実際の確率は

```text
そのランクの確率 = そのランクの値 ÷ 全部の値の合計
```

で決まります。上の例だと合計は 100 なので、そのまま

* GREEN … 60%
* RED … 30%
* GOLD … 10%

になります。合計は必ずしも100である必要はありません。例えば `green: 6, red: 3, gold: 1` と書いても、比率が同じ（6:3:1）なので結果は同じ確率になります。

**注意点**
* この確率は「番号」とは完全に切り離されています。何番の時にどのランクが出るかは決まっておらず、ガチャを回すたびに毎回この確率で抽選されます（普通のガチャガチャと同じ仕組みです）。カプセルのランクは見た目の演出だけで、プレゼントの中身とは連動していません。
* 一度引いた結果（番号とランクの組み合わせ）は `localStorage` に保存されるので、確率を後から変更しても、すでに引いた分の見た目が変わることはありません。次に引く分から新しい確率が反映されます。
* ランクの種類自体を増やしたい場合（例えば "silver" を追加する場合）は、
  1. `images/silver_close.png` と `images/silver_open.png` を用意する
  2. `CONFIG.images` に `silver_close: "images/silver_close.png"` のように2行追加する
  3. `CONFIG.rankWeights` に `silver: 20` のように1行追加する

  の3箇所を編集すれば使えるようになります。

### 3. 最後のメッセージ（`script.js` 冒頭 `CONFIG.text.completeMessage`）

コンプリート画面に表示される文章です。自由に書き換えてください。

### 4. ラスト賞の画像

`images/last_prize.png` を追加するだけで、ラスト賞画面に自動的に反映されます。
画像が無い間はシャンパンゴールドの仮表示（21という数字）になり、エラーにはなりません。

### 5. 効果音

`sounds/` フォルダに以下のファイルを置くと自動的に再生されます（無くても正常動作します）。

```text
sounds/gacha.mp3       … ガチャを回した時
sounds/capsule.mp3     … カプセルが出てくる時
sounds/open.mp3        … カプセルを開けた時
sounds/last-prize.mp3  … ラスト賞解放時
```

## 開発中のリセット

画面下部の「はじめから」から、記録を削除して最初から試せます（確認ダイアログあり）。

## 技術構成

Vanilla HTML / CSS / JavaScript のみ。外部ライブラリなし。
`localStorage` に進行状況を保存するため、ページを閉じても途中から再開できます。
バックエンドやデータベースは使用していません。
